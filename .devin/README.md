# .devin — agent configuration

[google/elephant-goldfish-model](https://github.com/google/elephant-goldfish-model)
(Apache-2.0 — see `EGM.LICENSE`). EGM = spec-driven development:

subagents) stress-test them. How this repo uses it: `../AGENTS.md`.
